# Инструкции проекта Look@LAN-ng

- Имя проекта и portable EXE: Look@LAN-ng / Look@LAN-ng.exe.
- Интерфейс поддерживает русский и английский языки.
- Визуальный стиль: современная компактная native Windows utility с лёгким налётом старого Look@LAN; чужие исходники, логотипы и графические ресурсы не использовать. Будущие значки делать современными, с лёгкой отсылкой к 90-м: ясные силуэты, аккуратная геометрия и сдержанные акценты; не воспроизводить устаревший clipart/pixel style буквально.
- Во всех поставках добавлять `© nr084, <год сборки>` в «О программе» и LegalCopyright в свойствах EXE. Год вычислять при сборке, не фиксировать в исходниках.
- Финальный EXE максимально сжимать последней стабильной версией UPX. Перед упаковкой проверять актуальную stable release; не использовать beta/RC. Использовать `--ultra-brute --lzma`, проверять результат `upx -t` и smoke-тестом запуска. Сохранять несжатую сборку для диагностики; не выдавать упаковку за успешную, если она или проверка не прошла.
- Начиная с v0.3, по прямому указанию пользователя GUARD_CF убрать для совместимости с UPX. Это уточнение заменяет исходное требование CFG и прежнее правило сохранять его. ASLR/NX/HIGHENTROPYVA сохранять. Release сжимать stable UPX максимально: `--ultra-brute --lzma`, затем проверять `upx -t` и запуск; не поставлять непроверенный packed EXE.
- Временные файлы после проверок очищать. Не удалять исходники, пользовательские attachments, документацию и нужные build outputs.
- Будущие release artifacts: `Look@LAN-ng-<версия>-win32.zip`, `Look@LAN-ng-<версия>-win64.zip`, `Look@LAN-ng-<версия>-linux.zip`, `Look@LAN-ng-<версия>-macos.dmg`. Windows 32/64 и Linux распространять ZIP, macOS — DMG. Эти цели расширяют исходную первую платформу Windows x64; не объявлять другие платформы готовыми до реализации и проверки.
- Следовать этапам полного ТЗ: v0.1 → v0.2 → v0.3 → v0.4 → стабилизация v1.00. После этапа собирать Release, выполнять соответствующие тесты и обновлять PROJECT_STATE.md.
- 12 октября 2026 пользователь явно разрешил выпустить stable 1.0.0 с перечислением непроверенных пунктов, без ожидания отдельной Windows 10/11 matrix. Это исключение не позволяет объявлять отсутствующие проверки пройденными. Отмечать реальное окружение, simulated DPI и оставшиеся ручные/LAN проверки в документации релиза.
- Основной код C17; frontend Win32; core без Windows headers. Никаких облаков, аккаунтов, telemetry, runtime/driver requirements или тяжёлых UI frameworks.
- Язык по умолчанию — язык системы Windows: русский → русский, любой другой → английский. Меню выбора: System language (default) / English / Русский; сохранять режим system/ru/en, явный выбор имеет приоритет.
- Публиковать готовые релизы сразу в публичный GitHub repository. Уточнение пользователя 12 октября 2026 заменяет прежние Windows artifact names: одна архитектура — один ZIP с одним EXE; `look@lan-ng-x86-<версия>.zip`, `look@lan-ng-x64-<версия>.zip`, `look@lan-ng-arm64-<версия>.zip`. Один release tag содержит три Windows ZIP. Описание репозитория/релиза на русском и английском. HIGHENTROPYVA применяется только к 64-bit targets; x86 сохраняет ASLR/NX.

Look@LAN-ng 1.3.0-rc.4 — local release candidate / локальный кандидат
© nr084, build year / год сборки

Русский
Кандидат не опубликован на GitHub. Для публикации требуются проверки именно
этой сборки; подтверждение работы предыдущей port.1 не заменяет их.

Оба порта: дерево сетей/сохранённых профилей; выбор IPv4-интерфейса; несколько
диапазонов; фоновое ARP/ICMP/TCP discovery; асинхронный reverse DNS→NBNS;
OUI; вероятностная ОС; common/custom TCP-порты; numeric сортировка; фильтр;
General/Ports/Ping/Trace/History/Log; notes текущей сессии; автоматический
monitoring; Single Host по IPv4/имени; context actions; редактор/UTF-8 профили;
фоновый атомарный CSV/TXT/HTML export; RU/EN/system и сохранение языка.
Старый ARP-кэш показывает UNKNOWN, только свежий ответ подтверждает ONLINE.
При недоступном интерфейсе импортированного профиля требуется явный выбор.

Ubuntu 22.04+ Desktop x64: распакуйте ZIP, запустите ./LookLAN.sh.
Нужны системные GTK 3 libraries (libgtk-3-0), графическая сессия и обычный
пользователь. Если распаковщик потерял права: chmod +x LookLAN.sh 'Look@LAN-ng'.
Native тесты выполняются на Ubuntu 26.04.1 x64 VM; 22.04 — только build baseline.
Настройки: ${XDG_CONFIG_HOME:-~/.config}/LookLAN-ng/.

macOS 13+: скопируйте содержимое DMG в доступную для записи папку.
Look@LAN-ng.app universal: Intel x86_64 + Apple Silicon arm64.
Подпись ad-hoc; нотариализации нет. Разрешите доступ к локальной сети.
Smoke-test.command проверяет собственный IP (0=успех, 77=нет активного IPv4).
Native-tests.command запускает дополнительные сетевые/файловые проверки
в изолированной временной конфигурации и сохраняет Native-tests.log рядом.
Проверьте вручную: монтаж DMG; запуск после копирования; собственный IP и
шлюз; имена/MAC/производителей; Ping/Trace; несколько диапазонов; monitoring;
Stop/закрытие во время scan; RU/EN/system; resize/колонки; профиль/save/open;
сохранённый профиль в дереве; Notes; фильтр; CSV/TXT/HTML; context actions.
Пришлите журнал Native-tests.log и скриншот главного окна. Эта версия ещё
не проверена на настоящем Mac. ARP route notifications и системный traceroute
особенно требуют native подтверждения. На Mac timeout Trace округлён вверх
до целой секунды: таков интерфейс системного traceroute. Полную проверку обеих архитектур
нельзя вывести из запуска на одной. Настройки приложения:
~/Library/Application Support/LookLAN-ng/; геометрия — NSUserDefaults.

English
This candidate is local only. Native validation must match this exact artifact;
previous port.1 startup confirmation does not validate the new functionality.
Both ports implement interface/profile trees, multiple IPv4 ranges, background
ARP/ICMP/TCP discovery, async reverse DNS→NBNS, OUI, probable OS, common/custom
TCP ports, numeric sorting/filtering, six details tabs, session notes/history,
automatic monitoring, single IPv4/hostname, context actions, profile editor,
UTF-8 profiles and atomic background CSV/TXT/HTML export, RU/EN/system language.
Cached neighbors alone are UNKNOWN; fresh responses prove ONLINE. Missing
profile interfaces require explicit selection. NetBIOS non-ASCII OEM names
remain unknown; mDNS, IPv6 active scan and persistent disk history are excluded.

Ubuntu 22.04+ Desktop x64: extract and run ./LookLAN.sh with system GTK 3.
Native tests use an Ubuntu 26.04.1 x64 VM; 22.04 runtime is not verified.
macOS 13+: copy the universal application out of the DMG, allow local network
access, run Smoke-test.command and Native-tests.command from a writable copy.
Send Native-tests.log and a main-window screenshot, and check the workflows
listed above. New macOS native results, route notifications and traceroute
are pending. The bundle is ad-hoc signed and not notarized. UPX is used where
supported; Mach-O is preserved if stable UPX rejects it, with LZMA DMG instead.
Notes/history are session-only. No new ports are published before validation.

Русский
Скачайте ZIP для своей архитектуры: look@lan-ng-x64-<версия>.zip на обычной
64-битной Windows, x86 на 32-битной Windows или arm64 на Windows ARM64.
Распакуйте ZIP и запустите Look@LAN-ng.exe.
Установка, драйверы и дополнительные runtime не нужны.
Выберите сетевой адаптер и нажмите «Сканировать» (F5). Esc / «Стоп» — отмена.
Язык: Вид → Язык → Язык системы / English / Русский.
По умолчанию русский язык Windows включает русский, любой другой — английский.
Для сохранения portable-настроек папка должна быть доступна для записи.
Реальная проверка всех сетей, адаптеров, Windows 10/11 и длительный мониторинг
не выполнена. Автоматические тесты не заменяют эту проверку.

English
Download look@lan-ng-x64-<version>.zip for standard 64-bit Windows, x86 for
32-bit Windows, or arm64 for Windows ARM64. Extract and run Look@LAN-ng.exe.
No installation, drivers or additional runtimes required.
Select a network adapter and press Scan (F5). Esc / Stop cancels the operation.
Language: View → Language → System language / English / Русский.
Russian Windows UI selects Russian by default; every other language selects English.
Use a writable folder to save portable settings.
The complete real-network, adapter, Windows 10/11 and long-running monitoring
matrix has not been tested. Automated tests do not replace these checks.

ZIP SHA-256 checksums are published in the GitHub release notes.
